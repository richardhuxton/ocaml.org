<p>John Crepezzi has spent his career building tools for other programmers—at Tumblr, at Square, and then at GitHub, where he worked on the merge queue and the early versions of Codespaces. He came to Jane Street to build a code search engine for OCaml. A week into the job, ChatGPT came out, and he’s been working on AI tooling ever since. In this episode, Ron and John talk about how a three-day prototype grew into a firmwide platform for agentic coding, how AI can break the social contract around code review, and how to build tools that support both agent workflows and human understanding.</p><p>You can find the transcript for this episode on our <a href="https://signalsandthreads.com/the-changing-craft-of-programming/" target="_blank" rel="noopener noreferrer">website</a>.</p><p>Some links to topics that came up in the discussion:</p><ul><li><a href="https://en.wikipedia.org/wiki/QBasic" rel="noopener noreferrer">QBasic</a></li><li><a href="https://en.wikipedia.org/wiki/Pirates_of_Silicon_Valley" rel="noopener noreferrer">Pirates of Silicon Valley</a></li><li><a href="https://hoogle.haskell.org/" rel="noopener noreferrer">Hoogle</a> — the Haskell API search engine that inspired the original code-search project</li><li><a href="https://github.blog/2023-07-12-github-merge-queue-is-generally-available/" rel="noopener noreferrer">GitHub merge queue</a> and <a href="https://github.com/features/codespaces" rel="noopener noreferrer">Codespaces</a></li><li><a href="https://sorbet.org/" rel="noopener noreferrer">Sorbet</a> — gradual typing for Ruby;
